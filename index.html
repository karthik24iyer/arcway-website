>_ Arcway: Remote Agents

Your terminal,
anywhere you go.

Arcway gives you secure, real-time terminal access to your Mac or Linux machine from your phone — no VPN, no port forwarding. Works seamlessly with agentic tools like Claude Code, running right from your pocket.

JWT + TLS secured

Only authenticated clients connect. Nothing is exposed publicly.

Self-hostable

Open-source relay server. Run it on any machine you own.

Self-host your relay

The relay is open-source and pairs to your apps with a 6-character code. One Docker command and you're live — no database, no OAuth setup, no manual TLS.

01

Clone & start with Docker

# Requires Docker (Compose comes bundled with Docker Desktop) git clone https://github.com/karthik24iyer/arcway-relay-server cd arcway-relay-server # Edit .env — set your DOMAIN (Caddy auto-fetches a Let's Encrypt cert) docker compose up -d
02

Grab your pair code

docker compose exec relay cat /data/.relay-code   # Output: a 6-character code, e.g. XK3F9P # Auto-generated on first boot, persisted on a Docker volume.
03

Pair the Mac & phone apps

In each app's login screen, flip the Self Host toggle, paste your relay URL (e.g. https://your-domain.com) and the pair code. The Mac registers as the agent; phones connect to it through the relay.

04

That's it

Every feature works exactly the same as the hosted Arcway — only the relay box and the pairing flow differ. No tier limits.

Requirements
  • Docker (Desktop or CLI)
  • A public domain pointing at the host (DuckDNS works free)
  • Ports 80 + 443 reachable for the auto-TLS cert
Quick deploy options
  • Any Linux VPS (Hetzner, DigitalOcean, ~$5/mo)
  • Home server behind Cloudflare Tunnel (no public IP needed)
  • Raspberry Pi behind Tailscale Funnel
